# Проектирование пользовательского интерфейса приложения "Моя Полка" (MyShelf)

## 1. Полный список экранов приложения

На основе имеющихся макетов выделено **5 экранов**:

### Основные экраны:
1. **Главный экран (Список книг)** — просмотр и управление коллекцией
2. **Экран редактирования книги** — изменение существующей записи (модальное окно)
3. **Экран подтверждения удаления** — модальное окно подтверждения
4. **Экран экспорта коллекции** — модальное окно выбора формата экспорта
5. **Главный экран с сортировкой** — вариант главного экрана с активной сортировкой по оценке

---

## 2. Описание экранов

### Экран 1: Главный экран (Список книг)

**Назначение:** Отображение всей коллекции книг с возможностью поиска, фильтрации и перехода к другим действиям.

**Элементы управления:**

| Элемент | Тип | Назначение |
|---------|-----|------------|
| `+ Добавить элемент` | Кнопка (правый верхний угол) | Переход к экрану добавления книги |
| `Поиск по названию` | Текстовое поле с иконкой лупы | Поиск книг по названию или автору |
| `Все статусы` | Выпадающий список (Dropdown) | Фильтрация по статусу чтения |
| `Название ↓` | Заголовок колонки таблицы | Сортировка по названию |
| `Жанр` | Заголовок колонки | Сортировка по жанру |
| `Статус` | Заголовок колонки | Сортировка по статусу |
| `Оценка` | Заголовок колонки | Сортировка по оценке |
| `Добавлено` | Заголовок колонки | Сортировка по дате добавления |
| `...` (в каждой строке) | Кнопка-меню (три точки) | Открытие контекстного меню (Редактировать, Удалить) |

**Отображаемые данные:**
- **Статистика в шапке:**
  - "8 элементов" (общее количество книг)
  - "8,0 средняя оценка" (средний рейтинг)
  - "4 из 8 завершено" (количество и статус)
- **Таблица книг** (колонки):
  - Название + автор (например: "Властелин колец: Братство кольца / Дж. Р. Р. Толкин")
  - Жанр (Фэнтези, Фантастика, Антиутопия, Роман)
  - Статус (цветные бейджи: зелёный "Завершено", жёлтый "В процессе", серый "Запланировано")
  - Оценка (формат "☆ X/10")
  - Добавлено (дата в формате ДД.ММ.ГГГГ)
- **Нижняя панель:**
  - "Показано 8 из 8 элементов"
  - "По дате добавления · Сначала новые" (текущая сортировка)

**Действия пользователя:**

| Действие | Реакция системы |
|----------|-----------------|
| Клик на `+ Добавить элемент` | Переход к экрану добавления книги (в разработке) |
| Ввод текста в поле поиска | Мгновенная фильтрация списка по названию ИЛИ автору |
| Выбор статуса в dropdown | Фильтрация списка по выбранному статусу |
| Клик на заголовок колонки "Оценка" | Переход к Экрану 5 (сортировка по оценке) |
| Клик на `...` в строке | Появление контекстного меню с пунктами "Редактировать", "Удалить" |
| Выбор "Редактировать" | Переход к Экрану 2 (Редактирование) с загрузкой данных книги |
| Выбор "Удалить" | Переход к Экрану 3 (Подтверждение удаления) |

**Обработка ошибок:**
- **Нет результатов поиска:** Показывается сообщение "Ничего не найдено. Попробуйте изменить запрос."
- **Ошибка загрузки БД:** Уведомление "Не удалось загрузить коллекцию. Проверьте файл базы данных."

### Экран 2: Редактирование книги (Модальное окно)

**Назначение:** Изменение данных существующей книги.

**Элементы управления:**

| Элемент | Тип | Назначение |
|---------|-----|------------|
| `Название *` | Текстовое поле | Ввод названия книги (обязательное) |
| `Год издания` | Числовое поле | Ввод года издания |
| `Статус` | Выпадающий список | Выбор статуса чтения |
| `Жанр` | Выпадающий список | Выбор жанра |
| `Авторы` | Поле с чипами + кнопка `+ Добавить` | Добавление авторов |
| `Оценка` | Ряд кнопок 1-10 | Выбор оценки |
| `Отмена` | Кнопка | Закрытие окна без сохранения |
| `Сохранить` | Кнопка (акцентная, зелёная) | Сохранение изменений в БД |

**Отображаемые данные:**
- Все поля **предзаполнены** текущими значениями из БД (например: название "Преступление и наказание", год "1866", статус "Завершено", жанр "Классика", автор "Ф. М. Достоевский", оценка "9")

**Действия пользователя:**

| Действие | Реакция системы |
|----------|-----------------|
| Изменение любого поля | Новое значение отображается в поле |
| Клик на оценку (например, `9`) | Кнопка подсвечивается зелёным, справа появляется текст "9 из 10" |
| Клик на `Отмена` | Закрытие окна **без сохранения** изменений, возврат на Экран 1 |
| Клик на `Сохранить` | Валидация → обновление записи в БД → закрытие окна → обновление списка на Экране 1 |

**Валидация (при нажатии "Сохранить"):**

| Поле | Правило | Сообщение об ошибке |
|------|---------|---------------------|
| Название | Не пустое, не только пробелы | "Поле 'Название' обязательно для заполнения" (красная рамка) |
| Год | 1000-2100 (если введён) | "Некорректный год издания" |

**Обработка ошибок:**
- **Ошибка валидации:** Поле подсвечивается красным, под ним появляется текст ошибки, окно НЕ закрывается.
- **Ошибка БД:** Уведомление "Не удалось сохранить изменения. Попробуйте позже."
- **Книга не найдена:** Сообщение "Книга не найдена (возможно, уже удалена)", окно закрывается.

### Экран 3: Подтверждение удаления (Модальное окно)

**Назначение:** Запрос подтверждения перед удалением книги.

**Элементы управления:**

| Элемент | Тип | Назначение |
|---------|-----|------------|
| Текст с названием книги | Статический текст | "Вы уверены, что хотите удалить книгу «Преступление и наказание»? Это действие нельзя отменить." |
| `Отмена` | Кнопка (белая с рамкой) | Отмена операции, закрытие окна |
| `Удалить` | Кнопка (красная) | Подтверждение удаления |

**Действия пользователя:**

| Действие | Реакция системы |
|----------|-----------------|
| Клик на `Отмена` | Закрытие окна, книга **не удаляется**, возврат на Экран 1 |
| Клик на `Удалить` | Удаление записи из БД (CASCADE удаляет связи) → закрытие окна → обновление списка на Экране 1 (книга исчезает) |

**Обработка ошибок:**
- **Книга уже удалена:** Уведомление "Книга не найдена (возможно, уже удалена)", окно закрывается.

---

### Экран 4: Экспорт коллекции (Модальное окно)

**Назначение:** Выбор формата экспорта данных коллекции.

**Элементы управления:**

| Элемент | Тип | Назначение |
|---------|-----|------------|
| `CSV` | Карточка-кнопка (с иконкой таблицы) | Выбор формата CSV (таблица) |
| `JSON` | Карточка-кнопка (с иконкой {}) | Выбор формата JSON (данные) |
| `Включить заметки и рецензии` | Чекбокс | Опция включения дополнительных полей |
| `Отмена` | Кнопка | Закрытие окна без экспорта |
| `Экспортировать` | Кнопка (акцентная, зелёная) | Начало экспорта в выбранном формате |

**Действия пользователя:**

| Действие | Реакция системы |
|----------|-----------------|
| Клик на карточку `CSV` | Карточка выделяется зелёной рамкой (выбор формата) |
| Клик на карточку `JSON` | Карточка выделяется зелёной рамкой |
| Отметка чекбокса | Чекбокс становится отмеченным |
| Клик на `Отмена` | Закрытие окна, возврат на Экран 1 |
| Клик на `Экспортировать` | Генерация файла в выбранном формате → диалог сохранения файла → закрытие окна |

**Обработка ошибок:**
- **Ошибка записи файла:** Уведомление "Не удалось сохранить файл. Проверьте права доступа к папке."
- **Пустая коллекция:** Уведомление "Коллекция пуста. Нечего экспортировать."

---

### Экран 5: Главный экран с сортировкой по оценке

**Назначение:** Вариант главного экрана с активной сортировкой по оценке (по убыванию).

**Отличия от Экрана 1:**
- Колонка "Оценка" выделена (активная сортировка)
- Книги отсортированы по убыванию оценки: 10, 9, 9, 8, 8, 7, 7, 6
- В нижней панели: "По оценке · Сначала высокие" (вместо "По дате добавления")

**Отображаемые данные:**
- Таблица книг в порядке убывания оценки:
  1. Властелин колец: Возвращение короля — 10/10
  2. Властелин колец: Братство кольца — 9/10
  3. Хоббит — 9/10
  4. Властелин колец: Две крепости — 8/10
  5. 1984 — 8/10
  6. Дюна — 7/10
  7. Мастер и Маргарита — 7/10
  8. Солярис — 6/10

**Действия пользователя:**
- Все действия аналогичны Экрану 1 (поиск, фильтрация, редактирование, удаление)
- Клик на заголовок "Оценка" переключает сортировку (asc ↔ desc)

## 5. Правила проектирования UI

1. **Принцип минимального количества кликов:** Любое действие (редактирование, удаление) выполняется не более чем за 3 клика.
2. **Мгновенная обратная связь:** Поиск и фильтрация работают в реальном времени (без кнопки "Применить").
3. **Защита от ошибок:** Деструктивные действия (удаление) требуют подтверждения.
4. **Визуальная иерархия:** Важные элементы (кнопка "Сохранить", название книги) выделены размером и цветом.
5. **Консистентность:** Все модальные окна имеют одинаковую структуру (заголовок, форма, кнопки "Отмена"/"Сохранить" внизу).
6. **Цветовое кодирование статусов:** Зелёный — "Завершено", жёлтый — "В процессе", серый — "Запланировано".
