| ID | Функция | Описание |

## Тест-кейсы для F01: Добавление книги

### TC-01.1: Успешное добавление книги (позитивный)
- **Приоритет:** Высокий
- **Предусловия:** Приложение запущено, БД инициализирована, справочники заполнены.
- **Тестовые данные:**
  - Название: "Преступление и наказание"
  - Год: 1866
  - Оценка: 9
  - Статус: "Завершено" (ID=3)
  - Жанр: "Классика" (ID=3)
  - Автор: "Фёдор Достоевский" (ID=3)
- **Шаги:**
  1. Нажать кнопку "+ Добавить элемент"
  2. Ввести название "Преступление и наказание"
  3. Ввести год "1866"
  4. Выбрать статус "Завершено"
  5. Выбрать жанр "Классика"
  6. Добавить автора "Фёдор Достоевский"
  7. Выбрать оценку "9"
  8. Нажать "Сохранить"
- **Ожидаемый результат:** Книга добавлена в список, модальное окно закрыто, счётчик элементов увеличился на 1.
- **Постусловия:** В БД создана запись в `items` и связи в `item_genres`, `item_authors`.

### TC-01.2: Пустое название (негативный)
- **Приоритет:** Высокий
- **Предусловия:** Открыта форма добавления книги.
- **Тестовые данные:** Название: "   " (только пробелы), остальные поля заполнены.
- **Шаги:**
  1. Очистить поле "Название" или ввести только пробелы
  2. Заполнить остальные поля корректно
  3. Нажать "Сохранить"
- **Ожидаемый результат:** Поле "Название" подсвечено красным, показано сообщение "Поле 'Название' обязательно для заполнения", окно не закрыто, книга не добавлена.

### TC-01.3: Оценка вне диапазона (граничный)
- **Приоритет:** Средний
- **Предусловия:** Открыта форма добавления.
- **Тестовые данные:** Оценка: 0 (ниже минимума) и 11 (выше максимума).
- **Шаги:**
  1. Заполнить название "Тест"
  2. Попытаться выбрать оценку 0 (если UI позволяет)
  3. Нажать "Сохранить"
- **Ожидаемый результат:** Система не позволяет выбрать оценку вне диапазона 1-10. Если ввод вручную — показывается ошибка "Оценка должна быть от 1 до 10".

### TC-01.4: Максимальная длина названия (граничный)
- **Приоритет:** Низкий
- **Тестовые данные:** Название длиной 200 символов и 201 символ.
- **Шаги:**
  1. Ввести название из 200 символов → сохранить (успех)
  2. Ввести название из 201 символа → сохранить (ошибка)
- **Ожидаемый результат:** 200 символов — сохраняется, 201 — ошибка "Название не должно превышать 200 символов".
